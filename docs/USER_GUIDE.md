# AxonMind 使用指南

AxonMind 是本地优先的知识与凭据工作台。你可以只用本机内容库，也可以按需连接飞书云盘和 AI 服务。本文按首次使用的顺序说明主要操作；功能总览及源码运行方式见 [README](../README.md)。

## 1. 安装与创建账户

1. 从项目的 [GitHub Releases](https://github.com/acid1030/vaultmind/releases) 下载与你的设备匹配的正式安装包。目前自动发布的是 macOS Apple Silicon（ARM64）版本；其他平台可按 README 从源码运行。
2. 打开 AxonMind，选择注册，填写邮箱或手机号、昵称和本地登录密码。
3. 注册完成后保存页面给出的恢复码，并在应用中确认已保存。恢复码应放在独立、安全的位置，不要保存在同一台电脑的明文笔记里。
4. 以后使用本地密码登录。连续输错可能触发临时限制；空闲一段时间后应用会自动锁定。

本地账户和飞书账户不是同一个密码体系。忘记本地密码时，只有事先保存的恢复码能帮助重置；忘记云端加密口令时，云端密文无法由服务端解开。

## 2. 保存和查找内容

在左侧进入「添加内容」，选择文件、文本、密钥、网页链接或视频链接，填写标题及内容。默认目的地是「保存到本机」，无需联网；仅在你主动选择加密同步时才会使用飞书连接。生产密钥建议先放在个人空间，再按需复制到用户组。

进入「知识库」可按标题或标签搜索，并按内容类型筛选。本机内容可以直接查看或打开；标记为云端待取回的内容，需要先点击「取回」并解密到本机。右侧「知识库对话」优先使用本地可用资料；若没有配置大模型，会明确显示本地检索结果，而不是假装生成 AI 答案。

## 3. 管理密码与密钥

在「密码库」中添加密码、API Key、SSH 密钥或令牌。列表默认只显示掩码；选中条目后在详情区主动「解锁查看」。敏感文本通过应用复制时，若剪贴板内容未被替换，应用会在约 30 秒后自动清空。共享、截屏或导出敏感内容前请确认周围环境安全。

密码库不是外部服务的账号恢复工具。删除条目或丢失本地/云端解密材料后，可能无法找回原始密钥。

## 4. 配置飞书加密同步（可选）

在「设置 → 飞书同步」选择一种接入方式：

- **AxonMind 托管**：仅在官方托管 OAuth 服务已配置的构建中可用；若页面显示等待上线，请使用自建方式。
- **个人自建**：用自己的飞书企业自建应用完成 OAuth 授权。
- **企业自建**：由企业管理员管理应用与权限。

自建方式需要在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，配置回调地址 `http://127.0.0.1:37891/feishu/oauth/callback`，并按 README 开通所需云盘权限。将 App ID、App Secret 填入应用后登录飞书，再设置独立的飞书加密口令。请在需要访问同一云端资料的设备上使用相同的加密口令。

首台设备在「同步中心」创建云端账号；其他设备用相同邮箱建立本机账户后选择「加入已有账号」。各设备可以使用不同的本地登录密码。自动同步可在登录、内容变更及定时任务时运行；需要立即刷新时点击「完整同步」。初次同步后请核对内容数量和设备状态。云端同步不能代替本地备份。

## 5. 用户组与开发连接（可选）

在「用户组」创建组后，可邀请已经注册 AxonMind 的同事邮箱。个人空间内容不会自动共享；需要共享时将内容复制到组。移除成员后，应轮换组密钥，并确认仍需访问的成员已重新获得权限。

「开发连接」可保存 Git/SVN 账号和仓库配置，并执行常见仓库操作。执行拉取、提交或推送前，请核对目标仓库与当前分支；这一功能不会替代 Git 的权限管理与代码审查。

## 6. 备份、恢复与更新

在「设置 → 数据安全」点击「立即备份」，可创建本地数据库备份；「打开备份目录」可查看位置。应用也会在发生数据变更时生成滚动备份。恢复时会先做完整性检查，并在替换当前数据库前保存一份保护性备份；恢复完成后需重新登录。建议另外定期备份到你信任的外部介质。

在「设置 → 版本更新」检查正式版本。升级旧版 VaultMind 到 AxonMind 0.4.0 时，应用会尝试迁移旧数据目录和偏好；由于 macOS 钥匙串身份变化，首次启动需重新登录。升级前请先手动备份。

## 常见问题

**必须配置飞书或 AI 才能使用吗？** 不需要。注册本地账户后即可保存、搜索本机内容。

**换电脑后为什么看不到内容？** 先确认两台电脑使用同一飞书云端账号和加密口令，在新设备选择「加入已有账号」，再执行完整同步。未同步到云端的本机内容不会自动出现。

**忘记密码怎么办？** 本地密码可尝试通过已保存的恢复码重置；飞书加密口令没有服务端找回途径。不要把恢复码、口令或原始密钥贴到公开 Issue。

**在哪里报告问题？** 在 [GitHub Issues](https://github.com/acid1030/vaultmind/issues) 提交操作系统、应用版本、复现步骤和已脱敏截图。请勿上传数据库、日志中的令牌、恢复码或个人资料。
