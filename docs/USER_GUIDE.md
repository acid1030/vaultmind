# 秘栈（AxonMind）使用指南

秘栈（AxonMind）是本地优先的知识与凭据工作台。你可以只用本机内容库，也可以按需连接飞书云盘和 AI 服务。本文按首次使用的顺序说明主要操作；功能总览及源码运行方式见 [README](../README.md)。

中文名称为「秘栈」，当前应用窗口、安装包及数据目录仍沿用 AxonMind。以下步骤中的 AxonMind 均指同一产品。

## 1. 安装与创建账户

1. 从项目的 [GitHub Releases](https://github.com/acid1030/vaultmind/releases) 下载与你的设备匹配的正式安装包。目前自动发布的是 macOS Apple Silicon（ARM64）版本；其他平台可按 README 从源码运行。
2. 打开 AxonMind，选择注册，填写邮箱或手机号、昵称和本地登录密码。
3. 注册完成后保存页面给出的恢复码，并在应用中确认已保存。恢复码应放在独立、安全的位置，不要保存在同一台电脑的明文笔记里。
4. 以后使用本地密码登录。连续输错可能触发临时限制；空闲一段时间后应用会自动锁定。

本地账户只存在于当前设备的数据目录；首次启动空白数据目录时需要注册，自动化测试账号不会保留在日常使用的数据中。同一云端账号换设备的配置方式见后文「个人多端留言与用户组群聊」。

本地账户和飞书账户不是同一个密码体系。忘记本地密码时，只有事先保存的恢复码能帮助重置；忘记云端加密口令时，云端密文无法由服务端解开。

## 2. 保存和查找内容

在左侧进入「添加内容」，选择文件、文本、密钥、网页链接或视频链接，填写标题及内容。默认目的地是「保存到本机」，无需联网；仅在你主动选择加密同步时才会使用飞书连接。生产密钥建议先放在个人空间，再按需复制到用户组。

进入「知识库」可按标题或标签搜索，并按内容类型筛选。本机内容可以直接查看或打开；标记为云端待取回的内容，需要先点击「取回」并解密到本机。右侧「知识库对话」优先使用本地可用资料；若没有配置大模型，会明确显示本地检索结果，而不是假装生成 AI 答案。

## 3. 管理密码与密钥

在「密码库」中添加密码、API Key、SSH 密钥或令牌。列表默认只显示掩码；选中条目后在详情区主动「解锁查看」。敏感文本通过应用复制时，若剪贴板内容未被替换，应用会在约 30 秒后自动清空。共享、截屏或导出敏感内容前请确认周围环境安全。

密码库不是外部服务的账号恢复工具。删除条目或丢失本地/云端解密材料后，可能无法找回原始密钥。

## 4. 配置飞书加密同步（可选）

在「设置 → 飞书同步」选择一种接入方式：

- **AxonMind 托管**：仅在官方托管 OAuth 服务已配置的构建中可用；若页面显示等待上线，请使用自建方式。
- **个人自建**：用自己的飞书企业自建应用完成 OAuth 授权。
- **企业自建**：由企业管理员管理应用与权限。

自建方式需要在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，配置回调地址 `http://127.0.0.1:37891/feishu/oauth/callback`，并按 README 开通所需云盘权限。将 App ID、App Secret 填入应用后登录飞书，再设置独立的飞书加密口令。请在需要访问同一云端资料的设备上使用相同的加密口令。

首台设备在「同步中心」创建云端账号；其他设备用相同邮箱建立本机账户后选择「加入已有账号」。各设备可以使用不同的本地登录密码。自动同步可在登录、内容变更及定时任务时运行；需要立即刷新时点击「完整同步」。初次同步后请核对内容数量和设备状态。云端同步不能代替本地备份。

## 5. 用户组与开发连接（可选）

在「用户组」创建组后，可邀请已经注册 AxonMind 的同事邮箱。个人空间内容不会自动共享；需要共享时将内容复制到组。移除成员后，应轮换组密钥，并确认仍需访问的成员已重新获得权限。

「开发连接」可保存 Git/SVN 账号和仓库配置，并执行常见仓库操作。执行拉取、提交或推送前，请核对目标仓库与当前分支；这一功能不会替代 Git 的权限管理与代码审查。

## 6. 备份、恢复与更新

在「设置 → 数据安全」点击「立即备份」，可创建本地数据库备份；「打开备份目录」可查看位置。应用也会在发生数据变更时生成滚动备份。恢复时会先做完整性检查，并在替换当前数据库前保存一份保护性备份；恢复完成后需重新登录。建议另外定期备份到你信任的外部介质。

在「设置 → 版本更新」检查正式版本。升级旧版 VaultMind 到 AxonMind 0.4.0 时，应用会尝试迁移旧数据目录和偏好；由于 macOS 钥匙串身份变化，首次启动需重新登录。升级前请先手动备份。

## 常见问题

**必须配置飞书或 AI 才能使用吗？** 不需要。注册本地账户后即可保存、搜索本机内容。

**换电脑后为什么看不到内容？** 先确认两台电脑使用同一飞书云端账号和加密口令，在新设备选择「加入已有账号」，再执行完整同步。未同步到云端的本机内容不会自动出现。

**忘记密码怎么办？** 本地密码可尝试通过已保存的恢复码重置；飞书加密口令没有服务端找回途径。不要把恢复码、口令或原始密钥贴到公开 Issue。

**在哪里报告问题？** 在 [GitHub Issues](https://github.com/acid1030/vaultmind/issues) 提交操作系统、应用版本、复现步骤和已脱敏截图。请勿上传数据库、日志中的令牌、恢复码或个人资料。

## 个人多端留言与用户组群聊

侧栏的「聊天」支持文字、图片与文件，与知识库里的 AI 问答分开。支持 Enter 发送、Shift + Enter 换行，每条文字最多 20,000 个字符，可带最多 5 个附件，每个不超过 12MB（12 × 1024 × 1024 字节）。消息先加密保存到本机；联网后，后台按同步中心配置的间隔上传、拉取（默认约 30 秒），也可以点击「立即同步」。这是一种基于飞书云盘的记录同步，不是即时通讯推送；暂不提供撤回、编辑、送达回执或未读通知。「已存云端」表示飞书存储成功，不代表其他人已经阅读。

### 自己的设备之间共享

1. 在主设备登录本地账号，在「同步中心」登录飞书，配置同步文件夹、加密口令，并创建云端账号。
2. 在其他设备使用相同邮箱注册/登录本地账号（本地密码可以不同），登录同一飞书账号，填写相同飞书加密口令，并选择「加入已有账号」。详细步骤沿用本指南的多设备账号配置。
3. 打开「聊天 → 个人留言」。发送的消息与附件会同步到其他设备；绑定云端账号之前保存的本机留言也会加入同步。

未连接飞书时仍可使用个人留言，界面会显示待上传数量。关闭自动同步后，请手动点击「立即同步」。退出本地账号后停止后台同步；重新登录后可继续查看已保存历史。修改本地密码会同时重新加密个人与群聊的本机副本。

### 不同用户之间群聊

1. 先在飞书创建一个共享文件夹，并向每位参与者的飞书账号授予访问权限。发送者需要读写权限；只读成员请仅授予读取权限。
2. 打开「聊天 → 新建群聊」，填写名称和文件夹 Token（飞书文件夹链接 `folder/` 后的部分）。聊天也可使用「用户组」中已有的组；已有组必须配置明确的共享文件夹，不能使用各人的 `root`。
3. 组所有者或管理员点击「邀请成员」，填写对方在 AxonMind 使用的邮箱或手机号，选择成员/只读，生成并复制邀请。
4. 对方在自己的设备登录本地账号和自己的飞书账号，选择「聊天 → 加入群聊」，粘贴邀请。成功加入后点击「立即同步」获取历史记录。
5. 同一成员的新设备也需要导入邀请。管理员可以为自己的账号生成邀请，在其他设备上恢复该组。

聊天邀请有效期为 7 天，包含群聊解密凭据，请仅通过可信渠道传递。邀请的账号匹配和角色限制由客户端检查；跨设备的实际云端访问权限以飞书共享文件夹权限为准。当前用户组成员管理列表仍是本机成员信息，并非跨设备的统一成员目录。

在本机移除成员或修改其角色不会自动修改飞书权限，也不能收回对方已下载的内容。撤销跨设备访问时，务必同时在飞书移除文件夹权限；需要阻止旧密钥读取后续消息时，可在用户组中轮换组密钥，并向保留成员重新发放新邀请。轮换后本机会将已保存的群聊历史重新加密上传到新密钥空间；其他设备导入新邀请后获取这些记录。轮换前尚未同步到执行轮换设备的消息需要先同步备齐。

### 存储与故障处理

- 消息正文、附件名称及二进制文件在本机 SQLite 和飞书云盘中均加密存储；个人云端记录使用已配置的飞书加密口令，群聊云端记录使用组密钥，不要求不同成员使用相同的个人加密口令。
- 云端以 `.axonchat` 文件保存不可变消息批次，每批最多 100 条，以 `.axonchatblob` 文件单独保存加密附件。多个设备各自追加，重复拉取按消息 ID 去重；不会覆盖其他设备的消息文件。请勿在飞书中随意删除这些文件。
- 本机按账号隔离历史，群聊按用户组隔离。历史超过 100 条时可点击「加载更早的消息」。
- 网络或权限错误会显示在聊天顶部；消息保留在本机等待补传。请检查飞书登录是否有效、个人云端账号是否已绑定、加密口令是否一致，以及所有成员是否能访问同一个共享文件夹。
- 群聊文件夹访问失败时直接报错，不会回退到个人根目录，以免其他成员无法获得消息。


### 截图、图片和文件

- **截图**：点击输入框上方的相机按钮，应用会暂时隐藏，使用 macOS 原生截图工具拖选区域。选区后打开标注窗口，可使用矩形、圆形、箭头、画笔、文字和马赛克，调整颜色、粗细和字号，支持撤销、重做和清空。文字 Enter 确认、Shift+Enter 换行；Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 重做。点击「完成并加入聊天」或 Cmd/Ctrl+Enter 后，图片进入待发送附件，检查后再点「发送」。Esc 取消截图或关闭标注（输入文字时先取消当前文字）。首次使用可能需要在「系统设置 → 隐私与安全性 → 屏幕录制」授权并重新打开应用（开发环境下可能显示为 Electron）。其他系统可使用系统截图工具，然后粘贴到输入框。
- **全局快捷键**：默认 macOS 为 `⌘⌥A`（Command+Option+A），应用解锁后可在其他应用中触发截图。聊天工具栏的「截图快捷键设置」支持录入新组合键；冲突时保留原快捷键。截图归入触发时的会话，草稿附件满时保留截图等待腾出位置，也可手动丢弃。
- **再次标注**：待发送图片上的铅笔按钮可打开同一标注窗口；完成后替换草稿中的原图，取消则保留原图。导出保留图片原始分辨率。
- **图片**：点击图片按钮选择 PNG/JPEG/GIF/WebP，或直接粘贴截图。图片进入草稿后可移除；发送后显示缩略图，点击查看原图，Esc 关闭预览。SVG、HTML 等内容作为普通文件处理，不作为图片执行或预览。
- **文件**：点击回形针按钮选择文件，也可将文件或图片拖入聊天区域。支持单发附件，也可附带文字说明。点击文件卡片的下载按钮，选择本地保存位置；应用不会自动执行文件。
- **大小与数量**：单个附件最大 12MB，每条消息最多 5 个附件。超限时会提示，不会发送半条消息。附件均上传成功后才发布该消息的云端引用；中途失败保留本机记录，下次同步继续。
- **跨设备查看**：聊天列表先获取附件信息，图片滚动到可见位置时下载缩略图，普通文件在保存时下载。下载的内容经过完整性校验，并加密缓存到当前本地账号；缓存后离线也能查看、保存。
- **改密和轮换**：修改本地密码会重新加密已缓存附件。轮换组密钥前，应用会先补齐本机群聊记录中尚未缓存的附件；下载失败则保留旧密钥并提示重试。轮换后重新加密上传附件，保留成员导入新邀请后可继续读取。
- **兼容性**：所有参与设备都需要更新到支持图片/附件的版本。此前的纯文字记录仍可读取，旧客户端无法读取带附件的新版消息批次。


## 工作台与管理页面

- **概览**：最近活动按内容入库与加密上传时间整理，可跳转对应模块；资产构成和设备列表来自当前账号可见数据，不是独立审计日志。
- **知识库**：分类右侧显示数量，可按入库时间或名称排序；选择条目后查看元信息，再主动打开或解锁。云端待取回内容需先下载。
- **密码库**：可筛选本机可用/云端待取回，按名称或入库时间整理凭据；项目账号按名称排序。筛选不会自动解锁秘密。
- **用户组**：左侧搜索组名，右侧按当前页搜索成员姓名/账号或共享标题；顶部显示角色、成员目录、共享数量和文件夹配置状态。成员目录为本机数据，云端权限以飞书授权为准。
- **同步中心**：查看待取回与冲突数量，按文件名和可用状态筛选记录；错误提示中可检查配置或重试同步。
- **添加内容**：右侧「保存前确认」随表单变化，提交前检查目标空间和保存方式；不会在确认区显示密钥正文。
- **开发连接**：支持仓库搜索；操作记录仅保存本次打开页面后的最近执行结果，重新进入页面不会保留，也不代表后台持续监控仓库状态。
- **设置**：顶部状态卡片可跳转对应配置，下方可搜索配置分类；状态反映已保存的配置，实际连通性仍以测试连接或同步结果为准。

## 好友与私聊

在「聊天」左侧的「好友」区域，点击添加好友，填写对方登录所用的邮箱或手机号，以及双方拥有读写权限的飞书文件夹 Token。建议每段私聊使用独立文件夹，仅授权双方。

1. 邀请人生成好友邀请码，经可信渠道发送给对方。
2. 对方在「导入邀请」中粘贴、查看账号信息，再选择确认或拒绝。确认后将生成的确认码回传。
3. 邀请人也在「导入邀请」中导入确认码，确认后双方进入同一个私聊。待确认邀请可以重新生成。
4. 私聊支持文字、图片、文件和截图。消息在本机加密保存，飞书登录及共享目录权限就绪后同步。

好友列表支持按名字、账号及备注搜索。在好友右侧的「···」中修改备注或移除好友。移除只停止本机访问并保留加密历史，不会删除对方已有记录，也不会替你撤销飞书权限；如需停止对方后续云端访问，请在飞书移除其共享目录权限。

自己的新设备登录同一账号后，可导入原设备好友资料中生成的「设备恢复码」，恢复该好友会话，再同步消息与附件。好友目录和备注暂不自动跨设备同步。邀请码、确认码及设备恢复码均含解密凭据，有效期七天，请妥善保管。没有公开账号搜索或自动发现服务。

## 飞书扫码登录与新机器恢复

登录页可直接选择「使用飞书扫码登录」，无需先注册本机账号、填写 App ID 或 App Secret。浏览器打开飞书授权页，可用飞书手机端扫码并确认。授权后输入原来的云端加密口令，秘栈从飞书云盘恢复同一个账号，并接续同步。首次使用则设置至少八位口令，在本机建立账号并创建云端账号资料。

旧账号迁移：先在原注册机器用原密码登录，再到「设置 → 飞书同步」点击「飞书扫码绑定本账号」，使用原加密口令完成绑定。此过程保留账号和资料归属。完成后再到新机器扫码。扫码流程只输入同步口令。如果旧库的本机密码不同，请使用独立的本机登录入口，或在新设备恢复已同步资料。

默认统一登录服务是 `https://axonclawx.cn/mizhan-auth`，凭据由服务器维护。普通用户不需要配置应用凭据。个人自建、企业自建和离线本机账号仍保留为高级方式。现有企业应用的登录范围以飞书后台的发布和可用范围为准，并非自动对所有企业开放。

加密口令仍是解密资料的必要条件，扫码不能找回口令。新机器第一次恢复会以输入的口令初始化本机解锁密码；之后可在本机修改，其他设备不受影响。好友目录仍按好友章节的设备恢复码流程迁移。
