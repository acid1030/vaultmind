# 好友功能测试

实现：独立好友目录、待确认邀请、邀请预览与主动接受/拒绝、确认码回传、备注、搜索、本机移除、同账号设备恢复码、一对一加密聊天。好友房间复用加密消息与附件传输，隔离于用户组列表，并禁止群邀请、角色变更等群管理操作。未授权账号不能读取本机好友记录；待确认或已移除联系人不能读写私聊。

核心验证：两个独立数据库确认关系，错误账号/损坏/过期码拒绝，重复导入幂等，文字双向同步与文件字节核验，新设备通过恢复码拉取历史，备注、删除、加密落盘。云端传输使用隔离的内存替身，不代表不同飞书用户实机权限验收。

运行：`npm run test:friends`、`npm run test:friends:e2e`。

边界：无中心账号搜索；共享目录读写权限需在飞书设置；好友目录和备注不自动跨设备同步；移除好友不等于撤销飞书权限。确认流程需要回传确认码，设备恢复也需主动导入。邀请码不能作为账号真实性的中心认证。
