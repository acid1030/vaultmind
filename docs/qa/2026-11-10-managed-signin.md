# 飞书统一扫码登录改造与部署

## 已完成

- 登录前即可启动托管授权，不依赖本机已注册用户。
- 原账号设置页增加扫码绑定入口。
- 授权完成后，先验证云盘权限、解密云端账号资料，再选择或创建本机账号；不直接复用远端密码哈希。
- 已有本机账号保留原解锁密码校验，飞书身份不允许接管绑定其他身份的本机账号。
- 新设备恢复云端 vaultId、邮箱及用户名，再合并设备并启用同步；自定义存储目录通过加密根目录定位资料发现。
- 服务端 Secret、刷新密钥不进入安装包或仓库；一次性票据、客户端 verifier 绑定、服务端独立 state、过期清理及加密刷新令牌。
- 腾讯云主机部署独立 systemd 服务，监听回环端口 3492，Nginx 专用 HTTPS 路径，访问日志关闭，原配置备份保存在非活动配置目录。
- 公网 `https://axonclawx.cn/mizhan-auth/health` 返回就绪，Nginx 语法检查通过。
