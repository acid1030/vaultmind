## 核对方法与范围

以 overview-concept.png、content-collaboration-concepts.png、connections-management-concepts.png 为视觉依据。保留用户要求的较暗配色。查看首页现有实现截图，并用独立 Electron 测试账号实拍其余八页（1600×1000、完整页面）。未使用真实用户账号、口令或云端数据。截图测试检查八页无横向溢出、无页面 JavaScript 异常；它不等于全部功能验收。

## 共性差异

- 全站页面标题区比设计稿高，部分页面右上空间仍空，挤占列表首屏。
- 模块颜色已区分，边框、内部分隔、按钮层级已统一一部分，但还未做到设计稿中紧凑的表格密度和一致的面板标题条。
- 首页与其他页面的标题条、统计字号存在差异，需要统一组件规范。
- 较暗配色是用户明确要求，不能把减少发光本身判成遗漏；应以文字辨识、选中态和边框层级为准。
- 截图中的测试条目数量不代表正式账号的数据。未覆盖长列表、大量附件、所有弹窗、错误与加载态。

## 逐页还原开发结果

- 首页：增大光球半径，保留动效、减少动态效果设置及真实统计。
- 知识库：名称/标签、类型、入库时间、操作独立分列；扩大中栏；没有云端记录时收起空同步块。
- 密码库：凭据名称、入库时间及解锁操作分列，保留遮罩与按需解锁。项目账号仍单独列示。
- 聊天：宽屏进入时默认展开资料第三栏，窄屏保持可切换。同名附件在消息区与资料栏分别验证操作。
- 用户组：成员、角色、权限管理独立分列，管理操作无需悬停；增加共享文件夹信息块及共享内容入口。
- 同步中心：提取横向设备区，压缩连接指引；同步记录按内容、上传时间、可用状态及操作分列；空态取消强制大高度。
- 添加内容：增加支持格式、保存位置及加密同步指引，放于表单右侧。
- 开发连接：增加终端/文件变更双栏；解析真实 Git/SVN Status 快照，并标明检查时间；修改类操作清除旧快照。Git Status 直接显示中文路径。
- 设置：增加分步配置指引；全站压缩标题，宽屏状态与操作移至右侧。

验证：UI 构建、八页隔离实拍、内容/密码库/用户组/同步设置/开发连接/聊天附件/窄屏/主题/首页动效回归均通过；Status 解析测试覆盖空状态、修改、新文件、空格文件名、重命名及 SVN。截图索引现指向更新后版本。

仍未实现的能力：收藏/目录树、会话未读/预览/群公告、成员在线与备注、文件拖放导入等，不能据本轮布局调整认定存在。真实云端多用户权限与多设备产品验收也不在隔离截图测试范围内。代码尚未提交或推送。

## 按 Medusa HTML 恢复光效与原色

用户反馈亮度不足后，以本地《Medusa 衣采中枢.html》的实际源码替换压暗参数：青 #5ee0ff、金 #ffc35a、粉 #ff4fa3、紫 #b77bff、绿 #5dffb0、蓝 #6f9dff。光球恢复白色光核、3+4.6×深度的粒子尺寸、原透明度与 .32/.28 双层加法泛光，粒子上限 4400，入球流线扩展为 12 组。保留确定性空间分布、离屏暂停和减少动态效果支持，不接入示例页面的虚构业务数据。

面板使用源 HTML 的 32% 原色描边、6% 顶部染色与内外泛光；按钮及选中标签使用原色描边和 35%/18% 内外光效，导航选中态使用完整原色边框。暗色与亮色截图已刷新。构建、首页动画与减少动态效果、八页实拍、明暗主题回归均通过。
