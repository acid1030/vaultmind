# 秘栈 A：霓虹多彩控制台

采用用户选定的 A 设计方向。生成稿为视觉参考，包含示例数据与部分尚未实现的展示元素，不代表已上线能力。

- `overview-concept.png`：首页设计方向。
- `content-collaboration-concepts.png`：知识库、密码库、聊天、用户组。
- `connections-management-concepts.png`：同步中心、设置、添加内容、开发连接。

## 已开始落地

- 侧栏所有项目使用独立颜色、彩色图标底块、边框和选中光效，设置固定左下角。
- 模块颜色：概览青色、知识库蓝色、密码库金色、添加内容橙色、聊天洋红、用户组紫色、同步中心绿色、开发连接蓝色、设置金色。
- 主内容区通过当前页面明确设置模块色，应用到标题、面板、表单、主要按钮与聊天气泡；样式位于 `ui/src/control-console.css`。
- 首页展示真实活动（按内容入库和上传时间整理）、资产构成、授权设备与快捷操作；首页光球为知识空间粒子视效，旁侧统计来自真实内容；不生成虚假业务统计。
- 保留现有表单、权限、加密、同步与快捷键行为，支持亮色模式与窄窗口。

## 后续精修

继续按实际内容与操作流程逐页细化，生成稿中的图谱分析、趋势统计、在线人数、语音/视频通话等不能作为已支持功能加入界面。需要对应实现和真实数据后才能展示。

## 内容与交互落地

- 概览：活动时间排序与模块跳转、五类资产数量和占比、当前空间可用性、授权设备列表、四个快捷操作；最近内容按入库时间排序。
- 知识库：分类数量、视频筛选、最近入库/名称排序、选择条目后显示类型、空间、存储状态和大小，提供打开/解锁操作；仅展示元信息，不自动解密凭据。
- 密码库：新增本机可用、云端待取回和项目账号三项状态摘要。
- 聊天：可展开会话资料，查看权限、已加载消息数和待同步数量；按文件名筛选已加载历史中的附件，并复用现有预览/保存流程。小窗口以可关闭的侧面板展示。
- 新交互已纳入内容与聊天附件 Electron 回归测试；构建、主题和响应式检查通过。

## 第二轮：管理与连接模块

- 用户组：组/成员/共享内容搜索、角色与目录配置摘要、角色对应的操作状态；成员搜索只针对本机目录，不声称云端统一成员列表。切换组时隔离迟到的成员请求。
- 同步：本机可用/待取回/冲突/最近结果摘要、文件名搜索和状态筛选、按上传时间排序、错误后的配置检查与重试。
- 添加内容：实时保存确认，展示类型、空间、保存方式、文件数量或标题与标签；凭据不显示明文预览。云端上传需已登录且具有加密口令。
- 开发连接：仓库搜索、右上新增入口、工作目录和授权账号、本次操作历史及结果；切换仓库不显示其他仓库的迟到输出，提交失败保留说明。
- 设置：模型/飞书/加密/备份状态卡片和可跳转入口、分类搜索及当前配置说明。
- 密码库：可用状态筛选、名称/时间排序、匹配数，继续保持明文按需解锁。

这些为现有功能范围内的内容与交互落地，不包含生成稿里未实现的业务能力；跨账号群聊权限及正式安装包验收仍须单独完成。

## 边框与控件精修

对照 A 稿统一面板 6px 圆角、按钮/表单 4px 圆角、模块色细描边与低亮度内高光。标题栏使用同模块渐变与分隔线；按钮使用深色填充和色边，顶部添加入口为金色。保留降低亮度后的配色，亮色模式单独适配。修复旧页面边框将 HSL 变量直接当作颜色的无效写法。

实际应用截图（隔离测试账号）：`implemented-overview.png`、`implemented-settings.png`。通过 UI 构建、主题全页面检查、响应式、聊天/附件和同步配置回归。

## 首页按稿补齐

- 顶部四个指标卡：知识规模、加密资产、团队协作、同步健康，各附最近 7 日实际入库/建组/上传趋势，不伪造增长率。
- 中部：左侧 Canvas 旋转粒子球和流光路径、内容数量及分类/标签分布；右侧最近活动与同步状态环。
- 底部：最近内容及类型筛选、协作空间与真实共享数量、授权设备摘要与列表。
- 粒子用于视觉示意，不代表推断出的语义关系。标签百分比为条目覆盖率，多标签可能重叠。设备授权不代表所有设备均已同步。
- 动效限约 30fps，设备像素比最高 2，离屏/后台暂停，卸载清理，遵循系统减少动态效果。亮色主题单独适配。
- 验证：`npm run test:dashboard`、`npm run test:dashboard:e2e`，及内容、响应式、主题回归。

## Medusa HTML 源码参考

按用户提供的本地《Medusa 衣采中枢.html》检查了 `V.orb`、`sprC`、`bloom` 和 `.p/.ph/.tag`。将体积粒子、缓存径向光斑、加色混合、成束贝塞尔路径、双尺度泛光、轻微呼吸与闪烁适配到 `KnowledgeOrb.tsx`。保留独立的动画生命周期控制、离屏/后台暂停与减少动态效果。粒子密度随显示面积调整，上限 3200，像素比上限 2，约 30fps。

面板采用近黑底、3px 小圆角、细模块色描边、低强度内发光；扫描线仅覆盖首页且不拦截点击。没有加载源码中的远程字体，也没有导入其随机采集数据、流水线模型或随机新增条目的行为。
